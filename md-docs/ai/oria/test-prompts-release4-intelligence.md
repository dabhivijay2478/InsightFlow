## How to use

1. Start Go API with `AGENT_RUNTIME_ENABLED=true` and intelligence tools enabled.
2. Open `/agents` in a workspace with sample pipelines (e.g. Stripe All Streams).
3. Send each **Prompt** verbatim; no manual context attach required.
4. Validate response against **What to verify** — forecasts must include confidence/assumptions/expiry; simulations must label what-if scenarios; lineage responses must use blast radius language.
5. Oria public identity only — responses must not expose internal agent or tool names.
6. No credentials, tokens, or raw secrets in responses.

## Response rules (Release 4)

- Intelligence outputs are **drafts** with confidence, assumptions, and expiry — never guaranteed outcomes.
- What-if and simulation prompts require labeled scenario comparison and impacted phases/streams.
- Lineage and blast-radius prompts must distinguish known vs inferred dependencies.
- Action/write operations remain out of scope — preview and plan only.
