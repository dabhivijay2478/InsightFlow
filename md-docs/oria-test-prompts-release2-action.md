# Oria Release 2 ACTION test prompts

Hand-crafted test corpus for the 12 Release 2 assisted-action specialists.
Every action prompt expects **preview-before-execute**: Oria shows the plan, risks, and waits for explicit confirmation before any write.

## Agents

| Agent | Focus |
| --- | --- |
| pipeline_builder | Create pipelines, clone skeletons, wire source→dest |
| connection_setup | Add/update source and destination connections |
| stream_selection | Add/remove selected source streams |
| schema_mapping | Column rename/map in connector_options |
| transformation_builder | SQL model create/edit/publish |
| replication_configuration | Set replication_key per stream |
| sync_configuration | FULL_TABLE vs INCREMENTAL per stream |
| schedule_manager | Cron, pause, resume schedules |
| run_controller | Start, cancel, resume runs |
| failure_recovery | Retry/recover failed runs |
| destination_manager | Bind schema.table destination targets |
| notification_manager | Failure/success alert rules (preview; execute may be partial) |

## Categories

`simple-valid`, `complex-valid`, `multi-step`, `ambiguous`, `missing-info`, `invalid`, `preview-required`, `confirm-flow`, `deny-confirmation`, `unsupported`, `edge`

## How to use

1. Enable Release 2 action runtime on the Go API (`AGENT_RUNTIME_ENABLED=true`).
2. Open `/agents` in a workspace with sample pipelines (e.g. Stripe All Streams, Postgres Incremental Sync).
3. Send the **Prompt** column verbatim or as a realistic variant.
4. Verify routing lands on the **Agent** specialist (internal only — user sees Oria).
5. Check **What to verify**: preview card, no silent writes, confirm/deny behavior, strict ELT invariants.
