# codex-skills (repo-local agent skills)

These are **project-specific skills** that explain how agents should work in *this* repository.

## Skills

- `mantrixflow-core/` — architecture + conventions + “where to change what”
- `supabase-rls/` — RLS workflow and policy rules for Supabase tables

## Adding a new skill

Create:

```
codex-skills/<skill-name>/SKILL.md
```

Keep skills:

- **Short and operational** (checklists, “do/don’t”, file paths)
- **Repo-specific** (avoid generic framework advice that already exists in global Cursor skills)
